# 🛡️ 학생부 순찰 앱

학생부 순찰 일정을 확인하고, 순찰 알림을 받고, 대타를 부탁하고, 부원끼리 연락하는 앱입니다.
아이폰·안드로이드 모두 **링크 하나로 설치**(홈 화면에 추가)할 수 있고, 앱스토어 등록이나 비용이 필요 없습니다.

## 주요 기능

| 화면 | 기능 |
|---|---|
| **홈** | 오늘·내일 순찰자, 나의 다음 순찰과 남은 시간, 도착한 대타 요청 |
| **일정표** | 월간 달력 / 목록 보기, 날짜별 순찰자, "내 순찰만" 보기. 관리자는 일정 추가·수정·삭제, **순번 자동 생성** |
| **대타** | 대타 요청 보내기(특정 부원 또는 전체 공개) + **문자 메시지 자동 작성**, 받은 요청 수락/거절 → 수락하면 **순찰표 자동 변경** |
| **연락** | 학생부 단체 채팅방, 1:1 채팅, 연락처(전화·문자 버튼), 전체 단체 문자 |
| **더보기** | 휴대폰 알림 켜기, 전날 알림·시작 N분 전 알림 설정, 내 순찰을 휴대폰 캘린더에 추가(.ics), 변경 기록, 백업(엑셀 CSV) |

**휴대폰 알림이 가는 경우**
- 순찰 **전날 저녁**(기본 20시) · 순찰 **시작 N분 전**(기본 10분)
- 나에게 **대타 요청**이 왔을 때 / 내 요청이 **수락·거절**됐을 때
- 관리자가 **내 순찰 일정을 바꾸거나 취소**했을 때 / 새 순찰표가 나왔을 때
- 채팅 메시지가 왔을 때

---

## 구조 (어떻게 동작하나요?)

```
 [부원 휴대폰 앱]  ⇄  Firebase (로그인 + 클라우드 데이터베이스, 무료)
                          ↑ 10분마다 확인
                  GitHub Actions 알림 발송기 (무료) ──▶ 휴대폰 푸시 알림
 앱 파일은 GitHub Pages(무료)에 올려서 링크로 배포
```

- `index.html`, `js/`, `css/` : 앱 화면
- `firebase-config.js` : Firebase 연결 설정 (**직접 입력**)
- `firestore.rules` : 데이터 보안 규칙 (임원만 접근, 관리자만 일정 수정)
- `notifier/` + `.github/workflows/notifier.yml` : 알림 발송 서버
- `sw.js`, `manifest.webmanifest`, `icons/` : 휴대폰 앱 설치·알림용

## 0단계 — 내 컴퓨터에서 미리보기 (데모 모드)

Firebase를 연결하지 않으면 **데모 모드**로 열립니다. 가짜 부원 10명과 일정이 들어 있어 바로 눌러볼 수 있어요.

```powershell
node tools/dev-server.js
```

브라우저에서 <http://localhost:5173> 접속 → 부원 이름을 눌러 로그인.
(데모 데이터는 그 브라우저에만 저장됩니다. 탭 두 개를 열어 서로 다른 부원으로 로그인하면 대타 요청·채팅을 주고받는 것도 시험할 수 있어요.)

---

## 1단계 — GitHub에 올리고 앱 주소 만들기

1. <https://github.com> 가입 → 오른쪽 위 **+** → **New repository**
   - 이름 예: `patrol` / **Public** 선택 → Create
2. **Add file → Upload files** 로 이 폴더의 내용을 전부 올립니다
   (`.github` 폴더도 꼭 포함. 숨김 폴더라 안 보이면 GitHub Desktop 사용을 추천)
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → Save
4. 1~2분 뒤 앱 주소가 생깁니다: `https://내아이디.github.io/patrol/`

---

## 2단계 — Firebase 프로젝트 만들기 (클라우드 저장)

1. <https://console.firebase.google.com> → **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. **웹 앱 추가**: 프로젝트 개요 옆 `</>` 아이콘 → 앱 이름 입력 → 나오는 `firebaseConfig = { ... }` 를 복사해서
   `firebase-config.js` 의 `self.FIREBASE_CONFIG = null;` 부분을 아래처럼 바꿉니다.
   ```js
   self.FIREBASE_CONFIG = {
     apiKey: "...", authDomain: "...", projectId: "...",
     storageBucket: "...", messagingSenderId: "...", appId: "..."
   };
   ```
3. **Authentication** → 시작하기 → 로그인 방법: **이메일/비밀번호** 사용 설정
   → 설정 탭 → **승인된 도메인**에 `내아이디.github.io` 추가
4. **Firestore Database** → 데이터베이스 만들기 → 위치 **asia-northeast3 (서울)** → 프로덕션 모드
   → **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여넣고 **게시**
5. **프로젝트 설정(톱니바퀴) → 클라우드 메시징** → 웹 구성의 **웹 푸시 인증서 → 키 쌍 생성**
   → 생성된 키(BL…로 시작)를 `firebase-config.js` 의 `self.FIREBASE_VAPID_KEY = "";` 따옴표 안에 붙여넣기
6. 고친 `firebase-config.js` 를 GitHub에 다시 올립니다.

> `firebase-config.js` 의 값은 공개되어도 괜찮습니다. 데이터 보호는 `firestore.rules` 가 합니다.

## 3단계 — 가입 코드 정하기 + 첫 관리자 지정

학생부 임원만 가입할 수 있도록 **가입 코드**를 만듭니다.

1. Firestore Database → **컬렉션 시작** → 컬렉션 ID: `config` → 문서 ID: `secret`
   → 필드 `joinCode` (string) = 원하는 코드 (예: `patrol2026`) → 저장
2. 앱 주소로 들어가 **회원가입** (가입 코드 입력)
3. Firestore → `members` 컬렉션 → **내 문서** → `isAdmin` 값을 `true` 로 바꾸기
4. 앱을 새로고침하면 **관리자 메뉴**가 생깁니다. 이후로는 앱 안에서
   - 더보기 → **순찰 시간대 설정** (등교/점심/하교 시간·장소·인원)
   - 더보기 → **순번 자동 생성** (기간·요일·공휴일 제외 → 순찰표 자동 작성)
   - 더보기 → **부원 관리** (다른 사람 관리자 지정, 졸업생 비활성화)
   - 더보기 → **가입 코드** 변경

---

## 4단계 — 알림 발송 서버 켜기 (휴대폰 푸시 알림)

1. Firebase **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성** → JSON 파일 다운로드
   ⚠️ 이 파일은 **비밀번호와 같습니다.** GitHub 저장소에 파일로 올리지 마세요.
2. GitHub 저장소 **Settings → Secrets and variables → Actions**
   - **Secrets** 탭 → New repository secret
     이름 `FIREBASE_SERVICE_ACCOUNT` / 값: 다운로드한 JSON 파일 내용을 **전부** 복사해서 붙여넣기
   - **Variables** 탭 → New repository variable
     이름 `APP_URL` / 값: `https://내아이디.github.io/patrol/`
3. 저장소 **Actions** 탭 → (처음이면 워크플로 사용 허용) → **순찰 알림 발송** → **Run workflow** 로 한 번 실행해서 초록색 ✔ 확인
4. 이후 10분마다 자동으로 실행됩니다.

---

## 5단계 — 학생부 임원에게 배포

단톡방에 **앱 주소 + 가입 코드**를 보내고, 아래처럼 설치하라고 안내하세요. (앱 안 더보기 → "휴대폰에 앱 설치하기"에도 같은 안내가 있어요)

- **아이폰**: Safari로 주소 열기 → 공유 버튼(□↑) → **홈 화면에 추가** → 홈 화면 아이콘으로 실행 → 회원가입 → **알림 켜기**
  (iOS 16.4 이상 필요. Safari 화면 그대로는 알림을 받을 수 없고, 반드시 홈 화면 앱으로 열어야 합니다)
- **안드로이드**: Chrome으로 주소 열기 → ⋮ 메뉴 → **앱 설치** → 회원가입 → **알림 켜기**

## 알아두면 좋은 점

- **비용**: Firebase 무료 요금제(Spark), GitHub 무료 범위 안에서 동작합니다. 신용카드 등록이 필요 없어요.
- **알림 시각 오차**: GitHub의 자동 실행은 정확히 10분 간격이 아니라 **5~15분 정도 늦어질 수** 있어요.
  그래서 대타 요청은 **문자 메시지로도 보내기**를 기본으로 켜두었고, 시작 전 알림은 10분 이상으로 두는 걸 추천합니다.
  앱이 열려 있으면 앱이 직접 시작 전 알림을 띄우고, 더보기 → **캘린더에 추가**를 하면 휴대폰 캘린더 알람으로도 받을 수 있어요.
- **방학 후 확인**: 공개 저장소는 **60일 동안 아무 변경이 없으면** GitHub가 자동 실행을 멈춥니다.
  개학 때 Actions 탭에서 **Enable workflow** 를 눌러 다시 켜 주세요.
- **앱 수정 후 배포**: 파일을 고쳐 올릴 때 `sw.js` 맨 위 `CACHE = 'patrol-v1'` 의 숫자를 올리면(v2, v3…) 모든 휴대폰에 새 버전이 반영됩니다.
- **백업**: 더보기 → 데이터 백업에서 순찰표를 엑셀(CSV)로 받을 수 있어요.
- **아이콘 다시 만들기**: `node tools/make-icons.js`
